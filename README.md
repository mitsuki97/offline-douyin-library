# Offline Douyin Library

一个面向 Windows 的本地视频整理、索引和离线播放器项目。

## 功能

- 按博主整理本地视频
- SHA-256 校验、完全重复检测和相似视频候选
- SQLite 本地索引
- 可回溯的文件操作记录
- 博主名称合并候选
- 本地网页工作台和竖屏播放器
- 测试模式与真实推荐模式隔离
- 播放行为、喜欢、跳过和屏蔽记录接口

## 数据边界

本仓库只保存代码和说明，不保存视频、图片、音频、SQLite 数据库、个人博主清单、操作日志或管理密码。

## 本地运行

1. 将代码放入项目目录。
2. 使用本机 Python 运行 `整理工具/web_app.py`。
3. 打开 `http://127.0.0.1:8765/`。

本地配置文件 `本地视频库/索引/web_config.json` 只在本机生成，不应提交到 GitHub。

## 目录

- `整理工具/library.py`：索引、媒体检查、查重和报告
- `整理工具/web_app.py`：本地网页工作台和播放器
- `整理工具/操作.ps1`：Windows 操作入口
- `整理工具/使用说明.md`：工作规则和恢复说明
# 本地抖音视频库

## 自动更新与批量下载

### 独立下载调试器

调试下载时可以单独启动：

```powershell
& 'E:\抖音企划\整理工具\启动独立下载器.ps1'
```

然后打开 `http://127.0.0.1:8766/`。这里可以先录入博主主页链接，再选择日期和登录方式。登录方式支持读取 Chrome、Edge 或 Firefox 的本机登录状态，也支持指定 Cookie 文件；不会保存账号密码。测试结果仍只写入 `本地视频库\待导入`。

项目内置基于 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 的下载任务。网页工作台只负责管理博主订阅、日期和任务；下载文件会先进入：

`本地视频库\待导入\博主名`

下载完成后，再通过现有导入流程执行媒体检查、查重和索引更新，避免下载失败或重复文件直接进入正式库。

使用步骤：

1. 打开 `http://127.0.0.1:8765/`，进入管理模式。
2. 打开“自动更新”，选择已有博主，填写公开主页链接和起始日期，然后加入订阅。
3. 点击“生成下载任务”，任务文件会写入 `本地视频库\更新任务`。
4. 在 PowerShell 运行：

```powershell
& 'E:\抖音企划\整理工具\运行下载任务.ps1' `
  -Task 'E:\抖音企划\本地视频库\更新任务\task_任务编号.json'
```

5. 下载结束后，把待导入目录交给网页中的导入流程，确认后再进入播放器。

下载器使用 archive 文件记录已经成功处理的视频，重复执行同一任务时会跳过已下载内容。开始日期只作为发现范围，平台页面可访问性和登录状态仍会影响结果；遇到需要登录的主页，应在本机浏览器准备好合法的 Cookie 后再运行。

## 可选的开源发现工具

- **yt-dlp**：体积小、适合作为本项目的下载执行器，已经接入。
- **MediaCrawler**：适合需要批量发现博主作品、评论或互动数据的场景；它属于发现/采集层，建议后续单独接入，下载文件仍走本项目的待导入流程。
- **DouyinTikTokDownload**：可作为抖音数据发现的备选实现，但维护状态和平台接口变化需要在使用前单独核验。

项目不把外部工具直接写入正式库，也不自动上传视频、图片、音频、SQLite 或博主清单。
