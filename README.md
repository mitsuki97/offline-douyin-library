# Offline Douyin Library

一个面向 Windows 的本地视频整理、索引和离线播放器项目。

## 功能

- 按博主整理本地视频
- SHA-256 校验、完全重复检测和相似视频候选
- SQLite 本地索引
- 可回溯的文件操作记录
- 博主名称合并候选
- 本地网页工作台和竖屏播放器
- 测试模式与真实推荐模式隔离
- 播放行为、喜欢、跳过和屏蔽记录接口

## 数据边界

本仓库只保存代码和说明，不保存视频、图片、音频、SQLite 数据库、个人博主清单、操作日志或管理密码。

## 本地运行

1. 将代码放入项目目录。
2. 使用本机 Python 运行 `整理工具/web_app.py`。
3. 打开 `http://127.0.0.1:8765/`。

本地配置文件 `本地视频库/索引/web_config.json` 只在本机生成，不应提交到 GitHub。

## 目录

- `整理工具/library.py`：索引、媒体检查、查重和报告
- `整理工具/web_app.py`：本地网页工作台和播放器
- `整理工具/操作.ps1`：Windows 操作入口
- `整理工具/使用说明.md`：工作规则和恢复说明
